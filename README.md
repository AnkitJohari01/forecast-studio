# Forecast Studio with TimesFM

Application source is in `forecast-studio/`. The Render Blueprint is `render.yaml` at this repository root; the frontend's Vercel root remains `forecast-studio/frontend`.

Start with [TimesFM setup](forecast-studio/TIMESFM_SETUP.md) and [validation results](forecast-studio/VALIDATION.md). This package contains source changes, not a deployed service. The separate TimesFM service must be hosted and connected using the server-side URL and token settings before TimesFM works in the hosted app.
